BAGIAN 1: Pilihan Ganda Tunggal (Soal 1 - 50)

1. Komponen utama sistem komputer yang bertindak sebagai pusat pengendali dan pemroses seluruh instruksi data adalah...
Kunci Jawaban: Central Processing Unit (CPU)

Pembahasan: CPU atau prosesor diibaratkan sebagai "otak" dari komputer. Semua perhitungan aritmatika, logika, serta kontrol aliran data antar komponen perangkat keras diproses di dalam CPU.

2. Perangkat keras masukan (input device) yang bekerja dengan memindai dokumen fisik menjadi data digital adalah...
Kunci Jawaban: Scanner

Pembahasan: Scanner memiliki sensor cahaya yang menangkap pantulan gambar atau teks dari dokumen fisik, lalu mengonversinya menjadi format file digital.

3. Jenis memori utama yang bersifat 'volatile' (data hilang saat listrik mati) adalah...
Kunci Jawaban: RAM

Pembahasan: RAM (Random Access Memory) menyimpan data instruksi secara sementara. Karena bersifat volatile, saat daya hilang, seluruh data terhapus.

4. Media penyimpanan sekunder berbasis chip semikonduktor tanpa komponen bergerak yang menawarkan kecepatan tinggi adalah...
Kunci Jawaban: Solid State Drive (SSD)

Pembahasan: SSD menggunakan chip NAND flash memory. Ketiadaan komponen mekanis membuat SSD lebih cepat dan tahan guncangan dibanding HDD.

5. Port pada motherboard yang secara khusus digunakan untuk memasang kartu grafis (VGA Card) modern adalah...
Kunci Jawaban: PCIe x16

Pembahasan: Peripheral Component Interconnect Express (PCIe) slot x16 memiliki bandwidth terbesar, khusus untuk transfer data grafis dari VGA/GPU.

6. Perangkat keluaran (output device) yang digunakan untuk mencetak cetak biru (blueprint) atau gambar teknis ukuran besar adalah...
Kunci Jawaban: Plotter

Pembahasan: Plotter adalah printer khusus untuk menggambar garis vektor presisi tinggi pada media besar seperti spanduk atau blueprint arsitektur.

7. Papan sirkuit utama yang menghubungkan seluruh komponen internal komputer satu sama lain disebut...
Kunci Jawaban: Motherboard

Pembahasan: Motherboard menyediakan konektivitas kelistrikan dan jalur bus agar komponen (CPU, RAM, dll) dapat berinteraksi.

8. Perangkat keras masukan yang biasa digunakan oleh desainer grafis untuk menggambar secara presisi dengan stylus adalah...
Kunci Jawaban: Graphics Tablet (Digitizer)

Pembahasan: Alat ini menangkap tekanan stylus dan menerjemahkannya ke goresan digital pada layar.

9. Komponen power supply yang berfungsi merubah arus listrik AC dari stopkontak menjadi arus DC untuk motherboard adalah...
Kunci Jawaban: Rectifier / Transformer

Pembahasan: Rectifier (penyearah) di dalam PSU mengubah arus PLN (AC) menjadi arus searah (DC) yang dibutuhkan komputer.

10. Teknologi port mentransfer data, sinyal video, dan daya listrik sekaligus dalam satu kabel kecil simetris adalah...
Kunci Jawaban: USB Type-C (Thunderbolt)

Pembahasan: USB Type-C (khususnya Thunderbolt) mendukung Power Delivery dan DisplayPort Alt Mode dalam satu kabel simetris.

11. Memori non-volatile berbasis ROM yang digunakan untuk menyimpan instruksi awal booting dasar sistem komputer adalah...
Kunci Jawaban: BIOS / UEFI Chip

Pembahasan: BIOS/UEFI di dalam ROM mengeksekusi POST dan memuat bootloader OS saat komputer dinyalakan.

12. Perangkat keras yang berfungsi mendinginkan CPU secara langsung melalui hembusan udara atau cairan pendingin adalah...
Kunci Jawaban: Cooler CPU (Heatsink & Fan)

Pembahasan: Menggunakan balok logam (heatsink) penyerap panas dan kipas (fan) untuk membuang panas dari prosesor.

13. Berikut ini yang termasuk perangkat penyimpanan optik adalah...
Kunci Jawaban: Blu-ray Disc

Pembahasan: Menggunakan sinar laser untuk membaca data. Standar Blu-ray jauh lebih besar kapasitasnya dibanding CD/DVD.

14. Sistem operasi tergolong ke dalam kelompok perangkat lunak kategori...
Kunci Jawaban: System Software

Pembahasan: System software adalah program inti yang mengelola hardware agar perangkat lunak aplikasi dapat berjalan.

15. Sistem operasi open-source berbasis kernel bebas yang dikembangkan oleh Linus Torvalds adalah...
Kunci Jawaban: Linux

Pembahasan: Dirilis tahun 1991, Linux bersifat open-source dan melahirkan banyak distro (Ubuntu, CentOS).

16. Perangkat lunak yang berfungsi menjembatani komunikasi antara sistem operasi dan hardware tertentu disebut...
Kunci Jawaban: Driver

Pembahasan: Device driver adalah penerjemah agar OS mengenali dan bisa memerintah perangkat keras keras spesifik.

17. Jenis lisensi perangkat lunak yang dapat digunakan secara gratis untuk jangka waktu percobaan tertentu sebelum membeli adalah...
Kunci Jawaban: Shareware

Pembahasan: Menawarkan masa uji coba (trial) gratis agar pengguna dapat mengevaluasi fitur sebelum membeli.

18. Program utilitas bawaan Windows yang berfungsi merapikan susunan fragmen file pada harddisk mekanis adalah...
Kunci Jawaban: Drive Defragmenter

Pembahasan: Menata ulang blok-blok data yang berserakan (terfragmentasi) di HDD agar berdekatan kembali sehingga pembacaan lebih cepat.

19. Perangkat lunak yang digunakan untuk menerjemahkan bahasa pemrograman tingkat tinggi langsung baris demi baris saat dieksekusi adalah...
Kunci Jawaban: Interpreter

Pembahasan: Berbeda dari compiler yang menerjemahkan seluruhnya sekaligus, interpreter mengeksekusi script baris demi baris secara langsung.

20. Contoh aplikasi yang tergolong dalam Spreadsheet (Pengolah Angka) adalah...
Kunci Jawaban: Microsoft Excel

Pembahasan: Menggunakan grid sel (baris & kolom) untuk mencatat, menghitung, dan memanipulasi angka (contoh: Excel, Google Sheets).

21. Perangkat lunak jahat yang menyandera data pengguna dengan cara mengenkripsinya lalu meminta tebusan adalah...
Kunci Jawaban: Ransomware

Pembahasan: Malware yang mengunci file penting dan memeras korban dengan meminta tebusan (uang kripto) untuk kunci dekripsinya.

22. Perangkat lunak firmware modern pengganti BIOS lama yang mendukung booting cepat dan kapasitas drive di atas 2.2 TB adalah...
Kunci Jawaban: UEFI

Pembahasan: Unified Extensible Firmware Interface, memiliki GUI, mendukung mouse, dan format partisi GPT skala besar.

23. Lisensi perangkat lunak bebas yang mewajibkan kode sumber turunan untuk tetap bersifat terbuka/bebas adalah...
Kunci Jawaban: GNU General Public License (GPL)

Pembahasan: Lisensi berkonsep copyleft yang mewajibkan setiap turunan karyanya tetap didistribusikan secara open-source bebas.

24. Aplikasi virtualisasi yang memungkinkan pengguna menjalankan beberapa sistem operasi secara bersamaan di atas OS utama adalah...
Kunci Jawaban: Oracle VirtualBox

Pembahasan: Merupakan hypervisor yang bisa menjalankan OS tamu (Guest) di dalam jendela OS utama (Host).

25. Program aplikasi yang digunakan khusus untuk mengelola, menyimpan, dan memanipulasi basis data berukuran besar adalah...
Kunci Jawaban: DBMS (Database Management System)

Pembahasan: Perangkat lunak khusus database (seperti MySQL, SQL Server) untuk mengelola data terstruktur dengan efisien.

26. Profesi brainware yang bertugas merancang, menganalisis, dan memetakan kebutuhan sistem informasi sebelum dibuat aplikasi adalah...
Kunci Jawaban: System Analyst

Pembahasan: Bertindak membuat blueprint (cetak biru) arsitektur sistem dengan menerjemahkan kebutuhan klien sebelum dieksekusi programmer.

27. Personel yang bertugas menulis baris kode program berdasarkan rancangan desain sistem dinamakan...
Kunci Jawaban: Programmer

Pembahasan: Menguasai bahasa pemrograman (coding) untuk mewujudkan desain analisis sistem menjadi aplikasi nyata.

28. Tingkatan brainware yang bertanggung menjaga keamanan, keandalan, dan kelancaran jaringan komputer organisasi adalah...
Kunci Jawaban: Network Administrator

Pembahasan: Spesialis yang mengatur konektivitas, router, server lokal, serta mengawasi keamanan lalu lintas internet perusahaan.

29. Pengguna komputer biasa yang menggunakan aplikasi untuk menyelesaikan pekerjaan harian tanpa mengubah sistem dinamakan...
Kunci Jawaban: End User / Operator

Pembahasan: Operator tidak memprogram ulang sistem, hanya memakai fungsi aplikasi yang sudah jadi (misal: Kasir).

30. Spesialis brainware yang bertugas mengelola integritas, keamanan, cadangan, dan struktur basis data perusahaan adalah...
Kunci Jawaban: Database Administrator (DBA)

Pembahasan: DBA menjaga ketersediaan (uptime), mengoptimasi kueri data besar, serta mengelola akses user pada database server.

31. Profesi IT yang berfokus pada pengujian kualitas lunak (mencari bug dan cacat sistem) sebelum dirilis adalah...
Kunci Jawaban: Quality Assurance (QA) Tester

Pembahasan: Mencari kecacatan (bug) dalam skenario penggunaan ekstrem agar aplikasi aman rilis ke publik.

32. Pihak yang memimpin seluruh jalannya proyek pengembangan perangkat lunak dari perencanaan hingga serah terima adalah...
Kunci Jawaban: Project Manager

Pembahasan: Mengatur jadwal, timeline (sprint), sumber daya tim developer, dan menjaga komunikasi dengan klien utama.

33. Teknisi yang bertugas merawat, memperbaiki, dan merakit perangkat keras komputer yang rusak dinamakan...
Kunci Jawaban: Teknisi Komputer / Hardware Technician

Pembahasan: Berhubungan dengan perangkat keras fisik, seperti menyolder, mengganti part rusak, atau melakukan perakitan ulang komponen.

34. Spesialis yang bertugas merancang antarmuka serta pengalaman kenyamanan pengguna dalam menggunakan aplikasi adalah...
Kunci Jawaban: UI/UX Designer

Pembahasan: Memastikan tata letak tombol estetik (UI) sekaligus memudahkan navigasi operasional psikologis pengguna (UX).

35. Orang yang menyusup ke dalam sistem komputer untuk tujuan menguji dan memperkuat pertahanan keamanan (Ethical) disebut...
Kunci Jawaban: White Hat Hacker / Penetration Tester

Pembahasan: Hacker baik yang dibayar secara legal untuk mencoba menjebol sistem perusahaan guna menambal celah sebelum diserang peretas jahat.

36. Petugas yang bertanggung jawab menginput data mentah ke dalam sistem komputer perusahaan secara rutin adalah...
Kunci Jawaban: Data Entry Operator

Pembahasan: Tenaga yang mengetik atau memasukkan data dokumen kertas secara masif ke dalam sistem basis data komputer.

37. Jabatan tertinggi dalam manajemen teknologi informasi di sebuah perusahaan yang menentukan arah kebijakan IT adalah...
Kunci Jawaban: Chief Information Officer (CIO) / CTO

Pembahasan: Pejabat eksekutif (C-Level) yang merancang visi, anggaran besar IT, serta investasi adopsi teknologi jangka panjang perusahaan.

38. Komponen dalam CPU yang bertanggung jawab melakukan operasi perhitungan aritmatika dan logika dasar adalah...
Kunci Jawaban: Arithmetic Logic Unit (ALU)

Pembahasan: Bagian sirkuit dari CPU yang mengeksekusi operasi tambah/kurang/kali/bagi serta perbandingan gerbang biner (AND/OR).

39. Komponen CPU yang bertugas mengatur lalu lintas data, mengkodekan instruksi, dan mengendalikan unit lain adalah...
Kunci Jawaban: Control Unit (CU)

Pembahasan: Bertindak sebagai "mandor" yang mengambil dan menerjemahkan (decode) instruksi memori lalu mengarahkan unit mana yang harus bekerja.

40. Register CPU yang berfungsi menyimpan alamat memori dari instruksi berikutnya yang akan dieksekusi dinamakan...
Kunci Jawaban: Program Counter (PC)

Pembahasan: Register khusus (penunjuk) agar CPU tahu baris perintah mana yang harus dilanjutkan setelah instruksi sebelumnya selesai.

41. Memori berkecepatan sangat tinggi yang berada di dalam atau dekat inti CPU untuk menyimpan data sementara yang sering diakses adalah...
Kunci Jawaban: Cache Memory

Pembahasan: Cache dirancang lebih cepat dari RAM untuk menjembatani jurang perbedaan kecepatan aliran data dari memori ke CPU.

42. Urutan siklus kerja dasar CPU dalam memproses suatu instruksi adalah...
Kunci Jawaban: Fetch -> Decode -> Execute

Pembahasan: CPU beroperasi mengambil (Fetch) instruksi dari memori, mengurai arti instruksi tersebut (Decode), lalu menjalankannya (Execute).

43. Register yang digunakan untuk menyimpan hasil sementara dari operasi perhitungan yang dilakukan oleh ALU adalah...
Kunci Jawaban: Accumulator

Pembahasan: Akumulator berperan menampung data matematika sesaat sebelum atau sesudah ALU melakukan kalkulasi numerik.

44. Bus sistem yang berfungsi membawa alamat lokasi memori atau I/O yang akan diakses oleh CPU adalah...
Kunci Jawaban: Address Bus

Pembahasan: Jalur kelistrikan searah yang digunakan prosesor untuk menunjuk/mencari laci lokasi data memori mana yang ingin dibaca/ditulis.

45. Satuan kecepatan detak gelombang jam internal CPU dalam mengeksekusi instruksi per detik diukur dalam...
Kunci Jawaban: Hertz (GHz)

Pembahasan: Menunjukkan seberapa banyak siklus yang dapat diselesaikan kristal osilator (Clock) dalam 1 detik. 1 GHz = 1 miliar siklus/detik.

46. Arsitektur prosesor yang menggunakan kumpulan instruksi sederhana dan berukuran tetap untuk eksekusi sangat cepat adalah...
Kunci Jawaban: RISC

Pembahasan: Reduced Instruction Set Computing (RISC) yang populer pada smartphone/ARM, unggul karena eksekusinya ringkas dan hemat baterai.

47. Teknik di mana CPU mengeksekusi beberapa tahap instruksi secara tumpang tindih (overlapping) untuk meningkatkan efisiensi disebut...
Kunci Jawaban: Pipelining

Pembahasan: Ibarat jalur perakitan pabrik. Selagi instruksi A di-execute, CPU bersamaan melakukan decode untuk instruksi B dan fetch untuk C.

48. Register CPU yang menampung instruksi yang sedang atau baru saja diambil dari memori utama adalah...
Kunci Jawaban: Instruction Register (IR)

Pembahasan: Menyimpan secara persis kode perintah biner yang dibawa masuk sebelum dipecah tugasnya oleh Control Unit.

49. Jenis bus yang bersifat dua arah (bidirectional) untuk lalu lintas mentransfer data antara CPU dan memori adalah...
Kunci Jawaban: Data Bus

Pembahasan: Jalur Data dapat mengalir dari CPU ke Memori (Write) atau ditarik dari Memori ke CPU (Read).

50. Teknologi pembuatan CPU yang menggabungkan beberapa unit pemroses (core) independen dalam satu chip fisik tunggal disebut...
Kunci Jawaban: Multi-Core Processor

Pembahasan: Beberapa otak prosesor fisik (misal: Quad-core, Octa-core) ditanam pada sekeping silikon mati untuk memperlancar kemampuan Multitasking.

BAGIAN 2: Pilihan Ganda Kompleks (Soal 51 - 100)

51. Manakah di antara perangkat berikut yang tergolong ke dalam perangkat masukan (input device)?
Kunci Jawaban: Barcode Scanner, Graphics Tablet, Touchscreen

Pembahasan: Ketiga perangkat tersebut berfungsi "memasukkan" sinyal/data (kode bar, tekanan pena, sentuhan jari) dari pengguna ke sistem komputer.

52. Pilihlah perangkat lunak/keras yang berfungsi sebagai media penyimpanan data non-volatile!
Kunci Jawaban: NVMe SSD, Harddisk External, Flashdrive USB

Pembahasan: Media non-volatile adalah penyimpan data permanen yang tidak hilang datanya walaupun tidak dialiri listrik/komputer dimatikan.

53. Berikut ini yang termasuk dalam kelompok perangkat keluaran (output device) adalah...
Kunci Jawaban: Monitor OLED, Speaker Active, Projector LCD

Pembahasan: Output device menghasilkan bentuk final terjemahan data komputer untuk dilihat (Monitor/Proyektor) atau didengar (Speaker) oleh manusia.

54. Komponen manakah yang terpasang langsung pada Motherboard komputer?
Kunci Jawaban: Prosesor (CPU), RAM Module, Expansion Card (VGA)

Pembahasan: Ketiga komponen ini dipasang menancap secara langsung pada slot soket internal motherboard di dalam casing PC.

55. Perangkat keras mana saja yang berhubungan langsung dengan pemrosesan sinyal grafis dan tampilan visual?
Kunci Jawaban: GPU (Graphics Processing Unit), VRAM, DisplayPort Cable

Pembahasan: Rantai sistem visual komputer melibatkan prosesor grafis (GPU), memorinya (VRAM), dan kabel penyalur (DisplayPort) menuju layar.

56. Manakah jenis konektor/port berikut yang digunakan untuk mentransfer data daya atau sinyal ke monitor?
Kunci Jawaban: HDMI, DisplayPort, VGA

Pembahasan: Ketiga antarmuka ini dirancang murni untuk menghantarkan gambar display layar dari kartu grafis ke monitor/proyektor.

57. Manakah ciri-ciri utama dari memori RAM pada komputer?
Kunci Jawaban: Bersifat Volatile, Kecepatan akses lebih tinggi dari Harddisk, Penyimpanan sementara program berjalan

Pembahasan: RAM (memori sistem) harus sangat cepat agar prosesor tidak nganggur, namun risikonya data bersifat sementara selama listrik hidup.

58. Berikut ini yang merupakan contoh media penyimpanan berbasis teknologi Flash Memory adalah...
Kunci Jawaban: Micro SD Card, SSD NVMe, USB Flashdrive

Pembahasan: Flash memory menahan data elektronik di dalam sel IC tanpa putaran disk mekanis sehingga senyap dan cepat.

59. Perangkat manakah yang memiliki fungsi ganda sebagai Input sekaligus Output (Hybrid Device)?
Kunci Jawaban: Layar Sentuh (Touchscreen), Headset (Headphone + Mic), Printer Multifungsi (Scan/Print)

Pembahasan: Sentuhan=Input/Layar=Output; Mic=Input/Speaker=Output; Scanner=Input/Printer=Output.

60. Faktor apa saja yang mempengaruhi performa kecepatan suatu Harddisk Mekanis (HDD)?
Kunci Jawaban: Kecepatan Putaran Spindle (RPM), Kapasitas Cache Buffer, Jenis Antarmuka Bus (SATA 3)

Pembahasan: Semakin tinggi RPM rotasi piringan magnetik (misal 7200 RPM) dan cache sementaranya, semakin ngebut HDD tersebut membaca data.

61. Perangkat jaringan mana yang tergolong perangkat keras pendukung sistem komputer?
Kunci Jawaban: Network Interface Card (NIC), Router, Switch Hub

Pembahasan: NIC sebagai kartu antarmuka fisik di dalam PC, Router mengarahkan rute IP, dan Switch membagi port kabel LAN lokal.

62. Manakah komponen yang berperan penting dalam menjaga suhu aman operasional komponen komputer?
Kunci Jawaban: Heatsink Aluminium, Thermal Paste, Kipas Casing (Case Fan), Liquid Cooling Radiator

Pembahasan: Thermal paste menambal pori agar rambatan panas mulus menuju Heatsink/Radiator air untuk didinginkan kipas.

63. Sebutkan jenis-jenis printer berdasarkan teknologi cetaknya!
Kunci Jawaban: Dot Matrix, Inkjet, LaserJet, Thermal

Pembahasan: Dot Matrix (pita ketuk), Inkjet (tinta semprot), LaserJet (serbuk laser magnet), dan Thermal (kertas pemanas nota kasir).

64. Manakah di antara sistem operasi berikut yang tergolong dalam kategori Open Source?
Kunci Jawaban: Ubuntu Linux, Fedora, Debian

Pembahasan: Ketiganya adalah turunan distro ekosistem kernel Linux yang kode intinya gratis dibedah atau diubah oleh komunitas publik.

65. Berikut ini yang merupakan contoh perangkat lunak program utilitas (Utility Software) adalah...
Kunci Jawaban: Antivirus (Kaspersky), WinRAR / 7-Zip, Disk Defragmenter

Pembahasan: Utilitas adalah software rawat jalan sistem, fungsinya spesifik untuk manajemen kompresi, perawatan disk, atau tameng keamanan.

66. Manakah tugas utama dari sebuah Sistem Operasi (Operating System)?
Kunci Jawaban: Manajemen Memori Utama, Manajemen File & Berkas, Manajemen Prosesor / Task, Manajemen Perangkat I/O

Pembahasan: OS adalah "pengatur jalan tol" bagi seluruh alokasi ruang memori, folder file, antrean proses CPU, serta perintah device input/output perangkat.

67. Pilihlah aplikasi yang masuk dalam kelompok Web Browser!
Kunci Jawaban: Google Chrome, Mozilla Firefox, Microsoft Edge, Brave Browser

Pembahasan: Program aplikasi khusus yang merender bahasa HTML dan script internet untuk berselancar di World Wide Web.

68. Berikut ini yang merupakan contoh Perangkat Lunak Aplikasi (Application Software) adalah...
Kunci Jawaban: Adobe Illustrator, VLC Media Player, Microsoft PowerPoint

Pembahasan: Aplikasi adalah program yang berjalan setelah OS nyala, untuk menyelesaikan spesifik pekerjaan produktif manusia tertentu.

69. Manakah karakteristik utama dari Perangkat Lunak Berbayar / Commercial Software (Proprietary)?
Kunci Jawaban: Kode sumber ditutup (Closed Source), Memiliki hak cipta yang dilindungi, Pengguna harus membeli lisensi

Pembahasan: Program komersial (contoh: Microsoft Windows) tidak mengizinkan kodenya diotak-atik karena memiliki entitas perlindungan profit developer secara legal.

70. Manakah aplikasi perkantoran yang berfungsi untuk pengolahan kata (Word Processor)?
Kunci Jawaban: Microsoft Word, Google Docs, LibreOffice Writer, WPS Writer

Pembahasan: Kumpulan aplikasi yang didesain dengan format blanko halaman putih (WYSIWYG) khusus untuk tata ketik persuratan atau laporan dokumen.

71. Manakah contoh ancaman perangkat lunak berbahaya (Malware)?
Kunci Jawaban: Virus, Trojan Horse, Ransomware, Spyware

Pembahasan: Semuanya adalah kategori Malicious Software; baik merusak sistem murni (virus) hingga pencurian intelijen secara siluman (spyware).

72. Bahasa pemrograman manakah yang tergolong dalam bahasa pemrograman tingkat tinggi (High-Level Language)?
Kunci Jawaban: Python, Java, C++

Pembahasan: Level tinggi berarti bahasa syntax kodenya mirip bahasa Inggris manusia sehingga sangat mudah diketik programmer dibanding machine biner.

73. Manakah jenis format berkas gambar berskala vektor maupun bitmap yang umum digunakan?
Kunci Jawaban: PNG, JPEG, SVG

Pembahasan: Ekstensi raster untuk foto solid padat (PNG transparan, JPG) serta basis desain vektor ringan dinamis tak pecah (SVG).

74. Manakah yang termasuk fungsi firmware dalam komputer?
Kunci Jawaban: Inisialisasi perangkat keras saat POST, Memuat bootloader sistem operasi, Menyediakan konfigurasi hardware dasar

Pembahasan: Perangkat lunak permanen cip motherboard (BIOS) bertugas mengontrol kelistrikan part sangat dasar sebelum memanggil Windows/OS.

75. Sistem operasi seluler (Mobile OS) yang populer digunakan saat ini adalah...
Kunci Jawaban: Android OS, Apple iOS, HarmonyOS

Pembahasan: Raksasa kernel operasi genggam yang diperuntukkan bagi sistem sentuh tablet maupun smartphone modern zaman sekarang.

76. Tugas-tugas yang menjadi tanggung jawab seorang Network Administrator meliputi...
Kunci Jawaban: Konfigurasi Router dan Switch, Monitoring lalu lintas jaringan, Mengatur hak akses dan keamanan jaringan

Pembahasan: Tim Network murni bermain logika di belakang layar kabel server atau transmisi, tanpa bersinggungan langsung dengan pembuatan aplikasi UI.

77. Manakah profesi IT yang berfokus pada tahapan pembangunan dan pembuatan kode aplikasi (Development)?
Kunci Jawaban: Front-end Developer, Back-end Developer, Full-stack Developer

Pembahasan: Posisi arsitek tulisan pemrograman. "Front" pada visual, "Back" pada kerangka koneksi fungsi, atau "Full" yang menguasai keduanya sekaligus.

78. Apa saja kemampuan mendasar yang wajib dimiliki oleh seorang System Analyst?
Kunci Jawaban: Pemahaman alur bisnis organisasi, Kemampuan pemodelan sistem (UML/DFD), Komunikasi & analisis masalah

Pembahasan: Tidak mutlak jago mengetik baris kode, tapi analis diwajibkan lihai menerjemahkan kebutuhan klien non-IT ke bahasa nalar skema UML.

79. Siapa saja yang tergolong ke dalam kelompok Brainware tingkat pengembang/pembangun sistem (System Developers)?
Kunci Jawaban: System Analyst, Software Engineer, Database Architect

Pembahasan: Trio pencipta kerangka inti aplikasi, arsitek sistemnya, arsitek alur logikanya, serta arsitek wujud tabel databasenya.

80. Tanggung jawab seorang Database Administrator (DBA) dalam perusahaan adalah...
Kunci Jawaban: Melakukan backup & recovery data, Menjaga keamanan data dari akses ilegal, Optimasi performa query database

Pembahasan: Penguasa ranah data. Bertanggung jawab jangan sampai tabel rusak/loss dan jika kueri sistem berat akan diatur index ulang.

81. Peran brainware dalam menjaga keamanan siber (Cybersecurity) organisasi dilakukan oleh...
Kunci Jawaban: Security Analyst, Penetration Tester, Chief Information Security Officer (CISO)

Pembahasan: Divisi pelindung serangan (Defensive). Mencakup penguji sistem, hingga dewan pengambil kebijakan mutlak infosec organisasi besar.

82. Etika dan tanggung jawab pengguna komputer (Brainware) yang baik antara lain...
Kunci Jawaban: Tidak menginstal aplikasi bajakan, Menjaga kerahasiaan kata sandi akun, Menghargai hak cipta karya digital

Pembahasan: Menghindari sengketa pirasi paten intelektual dengan memakai software original demi etika profesional kemanusiaan berjejaring siber.

83. Tugas utama tim IT Technical Support / Helpdesk di perusahaan adalah...
Kunci Jawaban: Membantu pengguna saat terjadi masalah IT, Menginstal OS dan aplikasi standar kerja, Melakukan troubleshooting perangkat komputer

Pembahasan: Barisan penjaga garda depan jika tiba-tiba sistem rekan kerja sekantor "ngambek", printer macet, kabel kusut, OS hank error blue screen.

84. Profesi manakah yang erat kaitannya dengan pengelolaan Big Data dan Kecerdasan Buatan?
Kunci Jawaban: Data Scientist, Machine Learning Engineer, Data Engineer

Pembahasan: Posisi saintis penguasa volume data statistik gila-gilaan, merekayasanya dalam struktur logaritma prediksi bot atau Artificial Intelligence generatif prediktif masa kini.

85. Komponen utama agar Brainware dapat bekerja efektif dalam sistem komputer meliputi...
Kunci Jawaban: Pengetahuan (Knowledge), Keterampilan (Skill), Sertifikasi / Pengalaman (Competency)

Pembahasan: Brainware merujuk pada elemen 'otak' sumber daya manusia, yang diukur dengan modalitas pengetahuan teori, wujud mahir praktik, hingga pengakuan sertifikat legal uji kompetensi.

86. Siapa saja pengguna komputer yang tergolong dalam kelompok 'Operator'?
Kunci Jawaban: Kasir minimarket menggunakan sistem POS, Petugas Data Entry di bank, Staf Administrasi mengetik surat

Pembahasan: Mereka tidak membuat arsitektur aplikasi (non-IT Developer), cukup memasukkan transaksi pada "end point UI/UX" program instan penunjang profesi utamanya.

87. Aktivitas jahat terkait brainware yang melanggar hukum siber (Cybercrime) adalah...
Kunci Jawaban: Phishing data nasabah, Carding / Pencurian kartu kredit, Hacking ilegal pada server

Pembahasan: Memancing link nipu curi akun user pass, penipuan e-commerce bayar bodong dengan kartu digital bajakan, hingga infiltrasi penetrasi DDoS jahat yang merusak data properti server.

88. Manakah komponen utama yang menyusun Arsitektur CPU Von Neumann?
Kunci Jawaban: Control Unit (CU), Arithmetic Logic Unit (ALU), Unit Memori (Memory Unit), Input/Output Unit

Pembahasan: 4 fondasi utama konsep klasik mesin von Neumann modern; pengatur sentral (CU), kalkulator aljabar (ALU), tabung ingatan memori, serta alur keluar-masuk perifer I/O terminal.

89. Manakah jenis register di dalam CPU yang berfungsi membantu aliran data instruksi?
Kunci Jawaban: Program Counter (PC), Instruction Register (IR), Accumulator (ACC), Memory Address Register (MAR)

Pembahasan: Tempat sandar ekstra kecil memori temporer, ada yang fokus mengingat barisan urut baris proses (PC), ada yang membawa wadah operand murni (ACC).

90. Fungsi dari Control Unit (CU) di dalam CPU antara lain adalah...
Kunci Jawaban: Mengambil instruksi dari memori utama (Fetch), Menerjemahkan kode instruksi (Decode), Mengatur sinyal kendali bus

Pembahasan: Ia layaknya pusat komando Polisi Lalu Lintas, cuma menginstruksikan arahan jalan bagi bus (Address/Data) tanpa turut ambil pusing menghitung tambah-kurang rumusnya.

91. Ciri-ciri utama dari Cache Memory pada CPU adalah...
Kunci Jawaban: Kecepatan akses jauh lebih cepat dibanding RAM, Kapasitas simpan relatif kecil, Letaknya sangat dekat/di dalam inti CPU

Pembahasan: Semacam 'kantong saku kemeja' pak mandor prosesor, sangat cepat dieksekusi diambil namun daya tampung Mega Bytenya super mini dan harganya paling mahal materialnya.

92. Manakah jenis bus internal yang menghubungkan CPU dengan komponen luar?
Kunci Jawaban: Data Bus, Address Bus, Control Bus

Pembahasan: Trio pipa sirkuit; pembawa lintasan kargo bit mentah (Data), penentu sasaran tembak peta laci memori (Address), pemegang komando instruksi interrupt kendali sinyal (Control).

93. Operasi dasar apa saja yang dilakukan oleh Arithmetic Logic Unit (ALU)?
Kunci Jawaban: Operasi Aritmatika (+, -, *, /), Operasi Logika (AND, OR, NOT), Operasi Perbandingan (==, >, <)

Pembahasan: ALU fokus mengekstrak bit listrik yang bermuara pada kalkulasi penambahan biner logika, membandingkan angka Boolean, dan operasi logika gerbang matematis kaku.

94. Faktor-faktor yang mempengaruhi kinerja dan kecepatan eksekusi sebuah CPU adalah...
Kunci Jawaban: Clock Speed (Frekuensi GHz), Jumlah Core / Inti Prosesor, Ukuran Kapasitas Cache Memory, Arsitektur Kumpulan Instruksi (RISC/CISC)

Pembahasan: Semakin ngebut sinyal gelombang clock (GHz), besar tabung cache dalam mb, atau rute arsitektur (ARM RISC nan gesit), semuanya berkolaborasi pada patokan tolok ukur 'Gahar' CPU itu.

95. Tingkatan Cache Memory yang umum berada dalam arsitektur prosesor modern meliputi...
Kunci Jawaban: L1 Cache, L2 Cache, L3 Cache

Pembahasan: Lapisan Hierarki 'Level'. L1 super kecil namun paling gila kecepatannya memandu inti, dilanjutkan L2 per-core buffer, baru kemudian buffer L3 besar patungan memori komunal shared unit CPU barengan.

96. Perbedaan utama antara arsitektur RISC dan CISC adalah...
Kunci Jawaban: RISC memiliki instruksi sederhana dan cepat, CISC memiliki instruksi kompleks yang beragam, RISC mengandalkan banyak register, CISC menggunakan format instruksi berukuran bervariasi

Pembahasan: RISC (Reduced) berorientasi memecah beban baris panjang menjadi ringan-ringan kecil eksekusi mutlak cepat (Smartphone/Apple M Series), beda dengan CISC (Complex) yang berat merangkap segalanya via memory panjang (Desktop intel/AMD PC).

97. Sebutkan tahapan dalam Siklus Instruksi (Instruction Cycle) CPU!
Kunci Jawaban: Fetch (Mengambil instruksi), Decode (Menerjemahkan instruksi), Execute (Mengeksekusi instruksi), Store (Menyimpan hasil)

Pembahasan: Putaran abadi jutaan kali per detik CPU. Menarik order dari RAM, memecah kode hex, jalankan tugas operasi oleh ALU, lalu write-back dikembalikan output ke register final memori utama.

98. Manakah keuntungan dari teknologi Multi-Core pada CPU modern?
Kunci Jawaban: Meningkatkan kemampuan Multitasking, Memungkinkan eksekusi paralel secara simultan, Efisiensi daya kerja beban terbagi

Pembahasan: Layaknya punya 4-8 tenaga kasir (pekerja) di satu toko (chip CPU), masing-masing orang dapat beroperasi sendiri merampungkan pelanggannya terhindar dari hang (Multithreading Paralel).

99. Sinyal yang dikirimkan oleh peranti I/O ke CPU untuk meminta perhatian eksekusi dinamakan...
Kunci Jawaban: Interrupt Request (IRQ), System Call, Control Signal

Pembahasan: Interupsi atau 'Interrupt' ini bersifat merajuk; ketika mouse diklik gerak atau USB HDD ditancap cabut tiba-tiba, komponen I/O ini memaksa nyela antrean CPU untuk diurusi seketika menyingkirkan program normal.

100. Manakah pernyataan yang benar mengenai konsep Pipelining pada CPU?
Kunci Jawaban: Membagi eksekusi instruksi menjadi beberapa tahap, Tiap tahap dikerjakan bersamaan untuk instruksi berbeda, Meningkatkan throughput pemrosesan instruksi

Pembahasan: Sistem aliran pabrik industri canggih. Bagian CU men-Decode file nomor B disaat bersamaan gerak ALU nge-Execute memukul palu data nomor A tanpa harus idle terbuang waktunya nunggu order.
